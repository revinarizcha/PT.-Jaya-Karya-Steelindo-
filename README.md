# PT.-Jaya-Karya-Steelindo-
PT Jaya Karya Steelindo adalah perusahaan yang bergerak di bidang perdagangan dan distribusi besi serta baja, khususnya menyediakan berbagai jenis material konstruksi seperti besi beton, besi hollow, besi siku, plat baja, H-Beam, dan produk baja lainnya untuk memenuhi kebutuhan pembangunan dan konstruksi.
